# 강호 수련록

Unity 기반 2D 세로형 무협 방치형 로그라이트 MVP 프로토타입입니다.

완성 게임이 아니라 수련, 자동 출행과 전투, 사망, 영구 성장, 새 회차로 이어지는 핵심 루프와 데이터 흐름을 검증하기 위한 개발용 프로젝트입니다.

## 핵심 루프

1. 입문 무공 선택
2. 수련과 경지 돌파
3. 강호 출행과 탐험
4. 탐험 사건 선택 또는 자동 전투
5. 전투 승리 시 보상 확인 및 다음 행동 선택
6. 계속 출행 또는 수련지 복귀
7. 사망 시 혼백 성장과 새 육신 선택
8. 새 회차 시작

## 현재 구현된 기능

### 입문 무공과 수련

- 입문 무공 3종
  - 청풍검식: 안정적인 피해와 추가 검격
  - 파문검식: 적 강공 준비 중 추가 피해
  - 회류보: 회피와 막기 중심의 생존 보정
- 일정 간격으로 검법 숙련도, 내력, 근력이 오르는 자동 수련
- 입문, 단련, 숙련의 3단계 경지와 선택형 돌파
  - 안정적 돌파
  - 무리한 돌파
  - 수련 계속하기

### 탐험과 전투

- 산길 진입, 비석 발견, 적 조우로 이어지는 자동 탐험
- 일정 확률로 발생하는 탐험 사건 3종
  - 검흔이 남은 비석
  - 독기 어린 약초밭
  - 부상당한 표사
- 사건 선택 결과가 체력, 내력, 수련 능력치, 전리품 또는 다음 전투에 반영
- 플레이어와 적의 자동 공격
- 서로 다른 상성을 가진 적 5종
  - 유엽 척후
  - 철갑 산적
  - 쇄맥 사혈객
  - 혈도 광전사
  - 흑풍채주
- 적 강공 예고와 회피, 막기, 집중, 강행돌파 대응
- 입력이 없으면 제한 시간 후 전투 성향과 적 특성에 맞춰 자동 대응
  - Adaptive
  - Defensive
  - Aggressive
- 직접 대응하면 자동 대응보다 먼저 적용되어 더 좋은 결과를 노릴 수 있음
- 계속 출행할수록 적 체력과 공격력이 증가하며, 수련지 복귀 또는 사망 시 출행 단계 초기화

### 승리 보상과 회차 성장

- 전투 승리 시 영혼 성장 포인트와 승리 횟수 획득
- 실제 효과가 적용되는 전리품 5종
  - 녹슨 검: 현재 회차 공격 피해 증가
  - 낡은 수련복: 최대 체력 증가
  - 깨진 옥패: 최대 내력과 내력 회복량 증가
  - 소형 회복단: 즉시 체력 회복
  - 흐릿한 혼백석: 즉시 영혼 성장 포인트 획득
- 지속형 전리품은 현재 회차에 최대 3중첩으로 유지
- 최대 중첩 아이템 재획득 시 영혼 성장 포인트로 변환
- 전투 승리 후 계속 출행 또는 수련지 복귀 선택

### 사망과 영구 성장

- 사망 후 육신 후보 3개 중 하나를 선택해 새 회차 시작
  - 검문 제자
  - 마교 잡역
  - 약밭 견습
- 새 육신 선택 시 경지와 현재 회차 전리품 초기화
- 선택한 입문 무공은 혼이 기억하여 다음 회차에도 유지
- 혼백 성장 3종, 각 최대 5레벨
  - 혼의 맷집: 새 회차 최대 체력 증가
  - 잔류 검의: 검법 수련 성장량 증가
  - 맑은 내력: 최대 내력과 내력 회복 보정

### 런타임 UI와 시각 프로토타입

- 1080 x 1920 기준으로 자동 생성되는 세로형 UI
- 상태별 전용 패널과 버튼 그룹
- 수련, 탐험, 전투, 승리, 사망, 육신 선택 상태별 배경 표현
- 전투 장면의 플레이어와 적 실루엣, 체력·내력 게이지, 공격·피격 연출
- 중앙 강공 경고와 선택 대응 버튼
- 최근 진행 로그, 현재 전리품, 혼백 성장 패널
- 접이식 Debug Control

## 실행 방법

1. Unity `6000.5.0f1`에서 프로젝트 폴더를 엽니다.
2. `Assets/Scenes/SampleScene`을 엽니다.
3. Game 뷰를 세로 비율로 설정합니다. 개발 기준 해상도는 `1080 x 1920`입니다.
4. Play 버튼을 누릅니다.

씬에 UI나 `GameManager`가 없어도 런타임에 기본 게임 루트와 세로형 UI가 자동 생성됩니다. Console 로그와 화면 로그에서 같은 진행 흐름을 확인할 수 있습니다.

## 조작과 자동 전투

- `B`: Training 상태에서 강호 출행
- `Q / W / E / R`: 강공 예고 중 회피 / 막기 / 집중 / 강행돌파
- `Space`: 사망 후 육신 선택으로 진행
- `1 / 2 / 3`: 입문 무공 또는 육신 후보 선택
- `F5 / F6 / F7`: 자동 대응 성향을 Adaptive / Defensive / Aggressive로 변경
- `F8`: 개발용 강공 예고 즉시 발생

전투는 키 입력 없이도 계속 진행됩니다. 강공 대응 시간이 끝나면 현재 자동 대응 성향, 체력과 내력, 입문 무공, 육신, 전리품, 적 특성을 바탕으로 기본 행동을 선택합니다.

## Debug Control

개발 테스트용 Debug Control은 화면의 `DEBUG` 버튼으로 접고 펼칠 수 있습니다.

- 전투: 즉시 전투 시작
- 사망: 플레이어 즉시 사망
- 육신: 육신 선택 상태로 이동
- 회복: 플레이어 체력과 내력 회복
- 적HP1: 현재 적 체력을 1로 변경
- 무공초기: 입문 무공 선택 초기화
- 저장 / 불러오기 / 초기화: 저장 데이터 제어
- 돌파준비: 다음 경지 조건을 채우고 돌파 화면으로 이동
- 전리품: 무작위 전리품 지급
- 사건: 탐험 사건 즉시 시작

혼백 성장 버튼은 Debug Control과 분리되어 있습니다. `UIManager`의 `showDebugControls`를 끄면 Debug Control 전체가 숨겨집니다.

## 폰트 설정

자동 생성 UI는 TextMeshProUGUI를 사용합니다. 기본 TMP 폰트에는 한글 글리프가 없을 수 있으므로 한글 TMP Font Asset 연결을 권장합니다.

1. 한글을 지원하는 `.ttf` 또는 `.otf` 파일을 `Assets/Art/Fonts/`에 넣습니다.
2. Unity에서 TMP Font Asset을 생성합니다.
3. `UIManager`의 `Runtime UI Font > Korean Tmp Font` 슬롯에 연결합니다.
4. Play 시 자동 생성되는 모든 TMP 텍스트에 해당 폰트가 적용됩니다.

폰트를 연결하지 않아도 실행은 계속되지만 한글이 네모로 표시될 수 있으며, 관련 경고는 한 번만 출력됩니다.

## 저장 시스템

`PlayerPrefs`에 `SaveData`를 JSON 문자열로 저장하는 프로토타입용 저장 방식입니다.

저장되는 주요 정보:

- 선택한 입문 무공
- 현재 회차와 육신 이름
- 현재 경지
- 현재 회차 지속형 전리품의 ID와 중첩 수
- 영혼 성장 포인트와 혼백 성장 레벨
- 총 사망 횟수와 총 전투 승리 횟수

입문 무공 선택, 전투 승리, 사망 보상, 새 육신 선택, 혼백 성장 강화 시 자동 저장됩니다. 이전 버전 데이터나 손상된 값은 가능한 범위에서 기본값으로 보정하며, 저장 초기화 시 영구 성장과 회차 전리품도 초기화됩니다.

현재 저장은 정확한 전투 도중 상태나 플레이어의 모든 임시 능력치를 복원하는 체크포인트 시스템은 아닙니다.
