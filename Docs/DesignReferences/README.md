# 디자인 참고 이미지

이 폴더의 이미지는 게임의 최종 화면이 아니라 시각적 방향을 공유하기 위한 콘셉트 이미지다.

주요 방향:
- 모바일 세로 화면
- 밝고 담백한 동양풍 무협 분위기
- 중국 양산형 모바일 게임처럼 과한 금색 장식, 한자 장식, 복잡한 메뉴는 피한다.
- 자동 수련·탐험·전투가 중심이며 중요한 순간에만 플레이어가 개입한다.
- 수련, 전투, 사망과 육신 선택, 경지 돌파가 시각적으로 구분되어야 한다.

이미지를 그대로 복제하기보다 현재 게임 구조에 맞게 해석한다.
게임 제목을 근거로 시스템을 설계하지 않는다.
